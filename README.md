# 🏥 Healthcare Management System

A full-stack Healthcare Management System built using Laravel to manage patients, doctors, and appointments efficiently. This system provides an easy-to-use interface for users and an admin panel for complete system control.

---

## 🚀 Features

- 👤 Patient Management System  
- 👨‍⚕️ Doctor Dashboard  
- 📅 Appointment Booking System  
- 🛠️ Admin Panel  
- 🔐 Secure Authentication System  
- 📱 Fully Responsive Design  

---

## 🛠️ Tech Stack

- **Backend:** Laravel (PHP)  
- **Frontend:** HTML, CSS, JavaScript  
- **Styling:** Bootstrap, Tailwind CSS  
- **Database:** MySQL

## ⚙️ Installation & Setup

Follow these steps to run the project locally:

```bash
# Clone the repository
git clone https://github.com/aalishbaifftikhar/Laravelproject.git

# Navigate into the project folder
cd Laravelproject

# Install dependencies
composer install

# Copy environment file
cp .env.example .env

# Generate application key
php artisan key:generate

# Run migrations
php artisan migrate

# Start development server
php artisan serve
